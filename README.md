# Vault – Distributed Object Storage Simulator

Vault is a simulation of a distributed object storage system designed to demonstrate how data can be stored, distributed, monitored, and recovered across multiple storage nodes.

## Key Features
- SHA-256 based data integrity verification
- Distributed file storage across nodes
- Data corruption simulation
- Automatic data repair and recovery
- Node heartbeat monitoring
- Storage metrics and monitoring
- Rebalancing and fault simulation

## Technologies Used
- Node.js
- JavaScript
- HTML
- CSS
- Node.js Crypto Module

## Project Goal
To understand the fundamental concepts of distributed storage systems, data integrity, fault tolerance, and automated recovery mechanisms.
